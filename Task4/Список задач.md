# Cписок крупных задач для каждой системы из ADR для будущего планирования

Сайт
- Разработка формы подачи заявки на депозит - создание интерфейса для новых клиентов с полями ФИО и телефон
- Интеграция с сервисом ставок - отображение актуальных ставок по депозитам на сайте
- Интеграция с депозитным сервисом - передача заявок на обработку

Интернет-банк
- Разработка раздела "Депозиты" - новый функционал для просмотра и подачи заявок
- Интеграция с сервисом ставок - получение персонализированных ставок для клиентов
- Интеграция с Kafka - асинхронная отправка заявок на депозиты

АБС (Автоматизированная банковская система)
- Интеграция с депозитным сервисом - получение и обработка заявок на депозиты
- Интеграция с сервисом ставок - передача данных для расчета ставок
- Доработка СМС-уведомлений - автоматическая отправка уведомлений о статусе заявок

Система кол-центра
- Интеграция с сервисом ставок - получение актуальных ставок для консультирования клиентов
- Доработка интерфейса - отображение информации о депозитных ставках операторам
- Обработка заявок с сайта - функционал для работы с заявками новых клиентов
- Интеграция с депозитным сервисом - передача данных о консультациях и заявках

Депозитный сервис (новый)
- Создание микросервиса - разработка на Java Spring Boot с PostgreSQL
- Интеграция с Kafka - асинхронная обработка заявок
- Интеграция с АБС - передача заявок на обработку бэк-офису
- Интеграция с системой кол-центра - синхронизация данных

Сервис ставок (новый)
- Создание микросервиса - разработка на .NET Core с MS SQL
- API для получения ставок - для сайта, интернет-банка, кол-центров
- Интеграция с АБС - получение данных для расчета персонализированных ставок
- API изменения ставок из клиента АБС - для управления ставками сотрудниками бэк-офиса
- Кэширование данных - обеспечение быстрого отклика (миллисекунды)

Шлюз партнерского кол-центра
- Интеграция с внешней системой - получение заявок от партнерского кол-центра
- Отправка файлов по email - ежедневная передача актуальных ставок менеджеру партнера
- Интеграция с сервисом ставок - получение актуальных данных
- Интеграция с АБС - передача заявок в общую систему обработки

Kafka (новый)
- Развертывание кластера Kafka - настройка очередей сообщений
- Настройка топиков - для обработки заявок на депозиты
- Мониторинг и алертинг - обеспечение стабильности работы

СМС-шлюз
- Модификация для новых уведомлений - поддержка уведомлений о статусе депозитных заявок
- Интеграция с депозитным сервисом - получение запросов на отправку СМС
